# 图片资源说明

请在此目录下添加以下图标文件：

## 必需图标

### 1. happy.png (首页Tab图标 - 未选中)
- 尺寸：81x81 像素
- 建议：笑脸或欢乐表情图标
- 颜色：灰色 (#999999)

### 2. happy-active.png (首页Tab图标 - 选中)
- 尺寸：81x81 像素
- 建议：笑脸或欢乐表情图标
- 颜色：主题红色 (#FF6B6B)

### 3. share.png (分享图片)
- 尺寸：500x400 像素 (5:4 比例)
- 建议：品牌展示或有趣的设计
- 内容：可以包含"哇哇笑"标题和一个可爱的表情

## 推荐获取方式

1. **免费图标网站**
   - https://www.iconfont.cn (阿里巴巴图标库)
   - https://www.flaticon.com
   - https://icons8.com

2. **AI 生成**
   - 使用 Midjourney、DALL-E 等 AI 工具生成
   - 提示词参考: "cute smiley face icon, simple style, pastel colors"

3. **设计软件**
   - Figma、Sketch、Adobe XD 等专业工具

## 快速方案

如果暂时没有图标，可以：
1. 使用纯色圆形占位
2. 或者从 iconfont.cn 下载免费图标
